# Minimum position size filter for SkewLS rejected

考慮過 [[min-position threshold filter]]：如果 SkewLS 某 ticker 在某日的 abs(weight) × alloc_skewls 不到 X% NAV（candidate threshold 3% 或 5%），當日不建該部位、capital 留現金。動機是 SkewLS 偶爾會輸出極小權重（如 XLF +0.1%）導致 1-2 股的訂單撞到 IB \$1 min/order，commission % cost 可達 100-200 bps，看起來像送錢給 broker。Reject：7 年 backtest（threshold sweep 0% / 0.5% / 1% / 2% / 3% / 5% / 7% / 10% × 2 scenarios = 16 cells）顯示在 [[Yvonne]] 實況 alloc (SR 0.35 / SkewLS 0.60) **threshold 1% 以上全部負分**：3% 門檻 Sharpe **-0.060** + MDD 從 -8.5% 惡化到 -10.0%、5% 門檻 Sharpe **-0.099**、10% 門檻 Sharpe -0.145；Pure SkewLS (alloc=1.0) 在 2% 有 marginal sweet spot (Δ Sharpe +0.003, +28 bps/yr) 但 2025-2026 已反轉（最近兩年 -52 → -141 bps）、sample size 太小不穩定。Friction 確實省（TC drag 從 0.575%/yr → 0.444%/yr at threshold 3% = **省 13 bps/yr**）但被 alpha loss 完全淹沒（-60 bps Sharpe-adjusted）。關鍵直覺：**SkewLS 小部位 ≠ noise，是 10 檔 long-short basket 的 diversification 一環**，砍掉等於告訴策略「你只能用 confident pick 賭」→ 報酬高峰但波動 / MDD 也放大、Sharpe & Calmar 雙降。表面上 annual return 過濾後升（+87 bps at 3%）會誤導，但 MDD 多虧 -156 bps，risk-adjusted 是負分。延伸觀察：threshold 越高、SkewLS deployed % NAV 越低（3% 時剩 45.89% NAV、10% 時只剩 23.9%）→ 越多 capital 閒置 in cash，bull market 機會成本明顯。研究腳本 `backtest/min_position_research.py` 留存可重跑（`python -m backtest.min_position_research`），若未來有 way 識別「真 noise 部位 vs 真 conviction 小部位」（例如用 z-score、skew confidence interval）可考慮重評；目前 baseline 不變。
