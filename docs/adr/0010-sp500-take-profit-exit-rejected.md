# SP500 take-profit exit rejected（噴出進場封鎖另立候選）

WDC/STX 2025-08~2026-03 回合高點回吐（STX 峰頂 442 → EMA50 出場 367.5，-17%）引發「[[停利 (Take-Profit)]]」提案：未實現獲利 ≥ X%（回合首筆進場價）且[[噴出 (Blowoff)]]（乖離/skew/kurt 超標）→ 週三 Rotation 第三賣出理由 + 同條件對稱封鎖進場（防 ADR-0005 rank 優先同輪買回使規則退化為 no-op）。設計 pre-registered（`robustness/takeprofit_study_design.md`，門檻以獲利中持股分位數 P80/90/95 錨定、grid 先登記）。**Reject（停利出場部分）**：8 年凍結資料（2018-07→2026-07-09）33 arms 顯示 (1) 乖離停利全 grid 慘敗 — 最緊門檻 CAGR 12.5% vs baseline 32.1%，砍高乖離贏家 = 砍掉動能策略的正偏尾部，方向與提案直覺**相反**；(2) 形式上過關卡一的 kurt60/skew60_P90 arms（Sharpe 1.24~1.25 vs 1.06）8 年只觸發 1~2 次停利，且兩筆皆壞出場（META 出場後一年 +53%、PLTR 出場後一年 +191% 且從未跌破出場價）；(3) 預登記拆解 arms 蓋棺：純出場（+冷卻）全部 ≤ baseline（Sharpe 1.017~1.054），純封鎖（零出場）**反而最好**（Sharpe 1.256）— 停利出場貢獻 ≤ 0，與 ADR-0004（停損零貢獻）同一教訓的獲利側鏡像。個股出場維持「只由週三 Rotation 負責」不變量。**副產品另立候選**：「噴出進場封鎖」（kurt60 > P90 不佔 rotation_buys 補位名額，比照 MAX_ADJ_SLOPE 模式；擋「漲相不穩」與既有擋「漲太快」互補）單獨通過 ADR-0005 同協議 WF gate — kurt60 與 skew60、N=8 與 N=7 全 PASS（pardo_chain 0.89~1.33，OOS np 勝率 5~6/8 折，每折 IS 窗重錨門檻 10.3~22.5 漂移仍穩定勝出），in-sample +6.1pp CAGR / MDD −29%→−24%（OOS 換算約 +3~5pp/yr），封鎖事件 44 次/21 檔平均分布 8 年非單一運氣。honest caveat：因子家族（60 日高階動差）是 15 組合 post-hoc 挑出，兩相關因子同過 WF 僅降低而未消除 selection 疑慮。**封鎖部署是 live 策略變更，未在本 ADR 決定** — 若部署需 characterization（OLD/NEW byte-diff + full pytest）+ 新 ADR + CONTEXT 詞條更新。研究可重跑：`robustness/takeprofit_{common,diagnostic,arms}.py`、`robustness/wf_takeprofit_block.py`；結案報告 `robustness/takeprofit_report.md`。
