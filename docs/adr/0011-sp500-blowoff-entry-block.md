# SP500 噴出進場封鎖（kurt60 > P90 不佔補位名額）

[[噴出 (Blowoff)]] 進場封鎖上線（2026-07-11）：[[Rotation]] 補位買入時，候選股 60 日日報酬 kurtosis（`kurt60`，Adj Close 優先、與 `robustness/takeprofit_common.blowoff_factors` 同源）> `BLOWOFF_KURT_MAX = 14.7712`（2018-07→2026-07-09 獲利中持股分布 P90 錨定）者**不佔補位名額** — 與 MAX_ADJ_SLOPE 過熱過濾並列的第二道進場濾網：一個擋「漲太快」（迴歸斜率），一個擋「漲相不穩」（少數極端日撐起的噴出走勢，財報跳空/軋空型）。**只擋買、不砍倉** — kept 持股不受影響（停利研究拆解證明抱住噴出贏家是對的，砍它是自殘，[ADR-0010](0010-sp500-take-profit-exit-rejected.md)）。來源：停利研究副產品 — 拆解 arms 顯示全部 edge 來自此封鎖（純封鎖 in-sample Sharpe 1.256 vs baseline 1.060、CAGR +6.1pp、MDD −29%→−24%，44 次封鎖/21 檔平均分布 8 年），純停利出場貢獻 ≤ 0。Gate：ADR-0005 同協議 WF（Pardo rolling，N=8+N=7，每折 IS 窗重錨 P90 防 lookahead）— kurt60 與 skew60 四組全 PASS（pardo_chain 0.89~1.33、OOS np 勝率 5~6/8 折、每折門檻 10.3~22.5 漂移仍穩定勝出）；OOS 換算約 +3~5pp/yr（in-sample 值視為高估）。與 ADR-0005 的張力已消解：當年 WF 否決的是**無條件** EMA 進場過濾（rank 優先勝出），本 ADR 是**條件式**封鎖（僅噴出狀態），同協議正面過 gate — rank 優先原則在非噴出狀態下完整保留；噴出股被 EMA 賣出後，同輪 rank 買回（續抱）會被本濾網擋下，屬刻意行為變更。實作（flag 閘門，`BLOWOFF_ENTRY_BLOCK`，翻 flag = 策略變更須重跑 WF）：metrics 組裝 `selection.calculate_metrics`（+kurt60 鍵）、判定唯一實作 `rotation.is_blowoff`、`rotation_buys` 過濾（一顆腦 — live 與 backtest 自動同源）、`signal.get_preview_weights` 內聯補位邏輯同步。Characterization（2026-07-11）：flag-OFF 全等價 — 8 年回測 706 trades 對 A0 **byte-identical**、preview_rebalance 3 帳戶×7 情境 + get_preview_weights 表面 9/9 SHA256 相同、pytest 299 綠；flag-ON — 8 年回測 692 trades 對研究 D1 arm **byte-identical**（生產實作 ≡ 研究實作，回溯驗證研究端 top-40 深度優化）；新增 5 條 rotation pin tests（不佔名額/strict >/NaN 不封鎖/不砍 kept/flag-off no-op）。Honest caveat（沿 ADR-0010）：kurt60/skew60 因子家族是 15 組合 post-hoc 挑出，兩相關因子同過 WF 僅降低未消除 selection 疑慮；門檻値為固定常數，維護上若成分股結構性改變可考慮以診斷 pass 重錨（重錨 = 參數變更，過 WF 才部署）。研究腳本防護：takeprofit_{arms,diagnostic,filter_matrix} 與 wf_takeprofit_block 已釘 `BLOWOFF_ENTRY_BLOCK=False`（研究 harness 自帶封鎖機制，live flag 開著會雙重過濾/污染 baseline 語意），rotation_buys 來源 hash 已 resync（426566ea4231）。回滾 = flag 翻 False（一行），行為即回 A0 — flag-OFF byte-diff 已證。
